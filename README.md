# Stocklyser

Stocklyser is a simple stock market analysis website that visualizes stock trends and provides basic insights using web technologies.

## Features

- View stock market information
- Visualize stock trends
- Explore basic stock analysis and insights
- User registration and login
- MongoDB database integration
- Simple and responsive web interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
